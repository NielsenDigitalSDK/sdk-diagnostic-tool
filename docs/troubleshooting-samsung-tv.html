📺 Samsung Tizen TV — Troubleshooting Guide

Complete troubleshooting reference for connecting the SDK Diagnostic Tool to Samsung Smart TVs. Covers HbbTV applications and Tizen Web Apps deployed via Tizen Studio.

Prerequisites

  • Samsung Smart TV with Developer Mode enabled
  • Mac/PC and TV on the same network
  • Tizen Studio installed (for Tizen Web Apps) OR Developer Mode enabled (for HbbTV apps)
  • Know your app type: HbbTV or Tizen Web App (this determines the debug port)

Which Port to Use?

This is the most common source of confusion. The port depends on your app type:

🚫
Port 26101 is NOT a debug port. Samsung's own documentation states: "Port 26101 is an internal device port. It cannot be opened separately." If you entered 26101, change it to the correct debug port for your app type.
App TypeDebug PortHow to Get It
HbbTV application 7014 (fixed) Built-in — just enable Developer Mode and reboot
Tizen Web App (via Tizen Studio) Dynamic (changes each session) Shown in Tizen Studio console when you "Debug As → Tizen Web Application"
SDB / device connection 26101 DO NOT use this port. This is Samsung's internal device port for app deployment, not debugging

Connection Flow

1

Enter the TV's IP address (find it on TV: Menu → Connection → Network → Network Status → IP Settings)

2

Enter the debug port (see table above)

3

Click Continue

4

The tool probes the TV to verify the debug server is reachable

5

If successful, launch or reload your app on the TV — the tool captures SDK logs in real-time

Error Reference

ErrorCauseFix
Connection timed out. TV did not respond within 10 seconds Wrong IP, wrong port, TV off, or not on same network Verify IP address, check port (see table above), confirm same network
Remote debugger not reachable. Confirm the TV is powered on and Developer Mode is active Port is closed — Developer Mode not enabled OR app not running in debug mode Enable Developer Mode (see below) and launch your app in debug mode
Debug server reachable but no debug targets found. Make sure the app is running Debug port is open but no app is active Launch or reload your app on the TV
Invalid IP address format Non-IPv4 value entered Enter a valid IP like 192.168.0.105
Invalid port number Port outside 1–65535 Enter the correct debug port

Enable Developer Mode on Samsung TV

1

Open the Apps panel on the TV

2

Using the remote, enter 12345 — a Developer Mode popup appears

3

Switch Developer Mode to ON

4

Enter your computer's IP address in the Host PC IP field

5

Restart the TV (required — Developer Mode activates only after reboot)

✅
Confirmation After reboot, a "Developer Mode" banner appears briefly at the top of the screen to confirm it's active.

For HbbTV Applications (Port 7014)

If your app is a broadcast HbbTV application (common for broadcasters like Mediametrie):

1

Enable Developer Mode on TV (steps above)

2

Switch to live TV and open the channel that triggers your HbbTV app

3

Verify from your computer

Open a browser and navigate to:

http://<TV_IP>:7014

If you see a Web Inspector page with a clickable link, the debug port is working.

4

In the IADT tool: enter the TV IP and port 7014, then click Continue

Requirements

  • Samsung 2024 D-series TV or newer (supports HbbTV Web Inspector)
  • Chromium-based browser on your PC (Chrome, Edge) for manual Web Inspector access
  • TV firmware must be up to date (Menu → Support → Software Update → Update Now)

For Tizen Web Apps (Dynamic Port via Tizen Studio)

If your app is deployed via Tizen Studio:

1

Open Tizen Studio

2

Connect to the TV

  • Open Device Manager (Tools → Device Manager)
  • Click Remote Device Manager → Add Device
  • Enter TV name, IP address, and port 26101 (this is only for SDB connection, NOT for debugging)
  • Click Connect
3

Launch app in debug mode

  • Right-click your project → Debug As → Tizen Web Application
  • The console output shows a URL like: http://192.168.0.105:7011
  • The number after the colon (7011 in this example) is your debug port
4

Enter that port in the IADT tool along with the TV's IP, then click Continue

⚠️
Important: The debug port is dynamic — it changes every time you launch in debug mode. Always check the Tizen Studio console for the current port.

Verifying Connectivity from Terminal

Before using the IADT tool, you can verify the TV's debug port is open:

# Check if the debug port is reachable (replace IP and port)
nc -zv 192.168.0.105 7014

# Or try fetching the debug target list
curl -s http://192.168.0.105:7014/json

Expected Results

  • nc: Should say "Connection ... succeeded" or "open"
  • curl: Should return a JSON array (e.g., [{"description":"","devtoolsFrontendUrl":"..."}])
💡
If both timeout or refuse: The debug server isn't running. Go back and verify Developer Mode is enabled and the app is launched in debug mode.

Common Mistakes

MistakeWhy It's WrongWhat to Do Instead
Entering port 26101 This is Samsung's SDB port (app deployment), not a debug port Use 7014 (HbbTV) or the port from Tizen Studio console
Entering port 7011 when app isn't launched in debug mode Port 7011 is only open when Tizen Studio actively debugs an app Launch app via "Debug As → Tizen Web Application" first
TV Developer Mode not rebooted Developer Mode only activates after a full restart Power off and on the TV after enabling
App running in normal mode Production/normal apps don't expose a debug port Must launch via "Debug As" in Tizen Studio, or use HbbTV path (7014)
PC and TV on different networks Debug connection requires direct network access Verify same subnet (both 192.168.x.x or both 10.x.x.x)

Still Not Working?

1

Update TV firmware

Menu → Support → Software Update → Update Now

2

Verify Developer Mode is active

After reboot, a banner should appear briefly at the top of the screen

3

Check TV IP hasn't changed

Re-check under Menu → Connection → Network → Network Status → IP Settings

4

Try port 7014 directly in Chrome

Navigate to http://<TV_IP>:7014 from your Mac. If it loads a debug page, use port 7014 in the tool.

5

Restart the TV

Some Samsung TVs require a fresh restart for Developer Mode to fully activate

6

Check Host PC IP

In Developer Mode settings, ensure the IP matches your current Mac/PC IP address

7

Disable TV power saving

Some Samsung TVs close debug ports when in standby or eco mode

Quick Checklist

Before starting, confirm:

  • Developer Mode is ON and TV has been rebooted after enabling
  • Mac/PC and TV are on the same network
  • You know your app type: HbbTV (port 7014) or Tizen Web App (port from Tizen Studio)
  • App is running on the TV (for HbbTV: channel is tuned; for Tizen: "Debug As" launched)
  • You are NOT using port 26101 (that's SDB, not debug)
  • TV firmware is up to date

For additional help, contact your Nielsen Technical Account Manager (TAM).
