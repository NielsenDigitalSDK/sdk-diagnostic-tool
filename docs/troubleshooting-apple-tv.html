📺 Apple TV — Troubleshooting Guide

Complete troubleshooting reference for connecting the SDK Diagnostic Tool to Apple TV devices via Wi-Fi. Covers the Discover, Pair, and Connect steps.

Prerequisites

  • macOS — Apple TV capture is Mac-only
  • tvOS 17 or later on the Apple TV
  • Mac and Apple TV on the same Wi-Fi network
  • Internet connection on first use (tool downloads dependencies automatically)

Connection Flow

The tool connects to Apple TV in three steps:

StepWhat HappensWhat You Need to Do
Discover Tool searches for Apple TVs advertising on the local network Keep Apple TV on Settings → Remotes and Devices → Remote App and Devices
Pair Tool exchanges a PIN with the Apple TV to establish trust Enter the 6-digit PIN shown on the TV screen
Connect Tool starts a tunnel daemon (requires Mac password) Enter your Mac login password when prompted

After Connect, the tool verifies that log data is flowing from the Apple TV.

Connect Step

ErrorCauseFix
Invalid password Wrong Mac login password Re-enter your Mac login password (the same one you use to unlock your Mac)
Device not connected to tunnel Tunnel started but Apple TV didn't connect — usually caused by too many existing pairings Clear all pairings on Apple TV (see Pairing Slot Exhaustion below)
Tunnel startup timed out First-run downloads took too long, or port conflict Ensure internet access; if repeated, restart the tool
Could not verify log stream Tunnel is up but syslog data isn't flowing Ensure the Apple TV is awake and on the home screen, then press Try Again

Known Issues & Fixes

Permission Fix

⚠️
Symptom: "Discovery failed due to a permission error in the Python cache (root-owned files from a previous 'sudo' run)"

This happens when a previous tunnel session wrote files as root into your user directories. The tool attempts to fix this automatically. If it can't, it shows a terminal command to run.

If the error says ~/.local/share:

sudo chown -R $(whoami) ~/.local/share

If the error says ~/.cache/uv:

sudo rm -rf ~/.cache/uv

If unsure, run both:

sudo chown -R $(whoami) ~/.local/share && sudo rm -rf ~/.cache/uv

Then press Try Again in the tool. This is a one-time fix — the latest tool version prevents this from recurring.

Pairing Slot Exhaustion

⚠️
Symptom: Discover and Pair succeed, but Connect fails with "Device not connected to tunnel"

Apple TV has a limited number of pairing slots under Remote App & Devices. When multiple tools (Xcode, the IADT tool, previous sessions) each hold a pairing record, the Apple TV may refuse new tunnel connections.

Fix:

1

On Apple TV: go to Settings → Remotes and Devices → Remote App and Devices

2

You'll see a list of paired devices (Macs, iPhones, etc.)

3

Forget (remove) all entries that you don't actively need

4

Go back to the tool and press Discover to start fresh

Stale Background Processes

⚠️
Symptom: Discovery fails intermittently, or "Device not connected to tunnel" appears after a previously working session

If the tool was force-quit or crashed, a background tunnel process may still be running and holding the Apple TV connection.

Fix:

sudo pkill -9 -f pymobiledevice3

Then relaunch the tool and reconnect.

Still Not Working?

If none of the above resolved the issue, try these steps in order:

1

Restart the Apple TV

Settings → System → Restart

2

Forget all pairings on the Apple TV

Settings → Remotes and Devices → Remote App and Devices → remove all entries

3

Run full cleanup on Mac

sudo chown -R $(whoami) ~/.local/share && sudo rm -rf ~/.cache/uv && sudo pkill -9 -f pymobiledevice3
4

Restart the Mac

Full restart, not just sleep/wake.

5

Relaunch the tool

Go through Discover → Pair → Connect again

6

VPN interference

If a VPN client is installed (even if disconnected), try temporarily uninstalling its network extension — some VPN clients interfere with multicast network discovery even when not actively connected.

Quick Checklist

Before starting, confirm:

  • Apple TV is on Settings → Remotes and Devices → Remote App and Devices screen
  • Mac and Apple TV are on the same Wi-Fi network
  • Apple TV is running tvOS 17 or later
  • No more than 2-3 entries under Apple TV's Remote App & Devices
  • Mac has internet access (needed for first-time setup only)
  • Tool is on the latest version

For additional help, contact your Nielsen Technical Account Manager (TAM).
